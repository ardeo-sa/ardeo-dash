# Ardeo Dash — Start here

Contribute or report an issue using our guided forms. If you plan to open a PR, please **sign the CLA (one-time)**.

## Quick actions

- ➡️ **Open issue chooser (bug/feature/CLA):**  
  https://github.com/ardeo-sa/ardeo-dash/issues/new/choose

- 🐞 **Bug report (form):**  
  https://github.com/ardeo-sa/ardeo-dash/issues/new?template=bug_report.yml

- ✨ **Feature request (form):**  
  https://github.com/ardeo-sa/ardeo-dash/issues/new?template=feature_request.yml

- ✍️ **Sign the CLA (one-time):**  
  https://github.com/ardeo-sa/ardeo-dash/issues/new?template=cla.yml

- 🔐 **Report a security vulnerability (private):**  
  https://github.com/ardeo-sa/ardeo-dash/security/advisories/new

- 📦 **View the repository:**  
  https://github.com/ardeo-sa/ardeo-dash

---

## What happens next?

- **Bugs & features**: issues are triaged using labels; please include steps to reproduce (bugs) or motivation/value (features).
- **CLA**: once signed, the `cla-check` workflow recognises you and allows your PRs to pass the CLA gate.
- **Security**: disclosures via **Security Advisories** are private by default.
