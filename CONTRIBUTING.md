# Contributing

Thank you for considering a contribution.

## 1. Before you start
- **Sign the CLA once**: open a new issue using the “CLA” template  
  👉 Sign here: ./../../issues/new?template=cla.yml
- Ensure CI checks pass locally where possible.

## 2. Branch & commit
- Branch from `main` (e.g., `feature/<short-title>` or `fix/<short-title>`).
- Use clear, descriptive commit messages.

## 3. Pull request
- Keep PRs focused; complete the PR template and link issues.
- CI and the **CLA** check must pass.

## 4. Reviews
- CODEOWNERS may be auto-requested; please respond to comments promptly.

> By contributing you agree to the project’s licence (`LICENSE`) and the CLA.
